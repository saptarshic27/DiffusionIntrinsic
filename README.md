# DiffusionIntrinsic
This is the accompanying code to our paper, [Generalization Properties of Score-matching Diffusion Models for Intrinsically Low-dimensional Data](https://arxiv.org/abs/2603.03700). The steps for running the code are as follows. 

1. Run the codes 'gen_goldfish_10.py" and 'gen_goldfish_100.py" to generate the intrinsically low-dimensional data.
2. Run the codes 'goldfish_10.py" and 'goldfish_100.py" on the data generated in step 1 to train and test the performance of the diffusion model, described in the paper.
3. Plot the results as shown in "plot.ipynb".
